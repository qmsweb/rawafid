# مرحبًا بكم في مدونة روافد

مرحبًا بكم في **مدونة روافد**! هذه أول تدوينة تجريبية نكتبها بلغة **مارك داون** لتجربة طريقة عرض المحتوى داخل المنصة.

## ماذا ستجد في هذه المدونة؟

نخطط لنشر تدوينات متنوعة، منها:

- ملخصات ومذكرات للمقررات الدراسية
- نصائح أكاديمية لطلبة اللغة العربية
- شروحات لأدوات المنصة التفاعلية
- أخبار النشاطات والفعاليات الجامعية

> **ملاحظة:** التدوينات تكتب بصيغة بسيطة ومرنة، ويمكن مشاركتها أو نسخها بسهولة.

## مثال على تضمين الأكواد

يمكن تدوين نصوص برمجية أو شفرات داخل التدوينات:

```js
function greet(name) {
  return "أهلًا بك يا " + name;
}
console.log(greet("زائر"));
```

## مثال على جدول

| الأداة | الوظيفة | الحالة |
| --- | --- | --- |
| التقويم الأكاديمي | متابعة الأسابيع والامتحانات | مفعّلة |
| توثيق المراجع | تنسيق المراجع وفق APA | مفعّلة |
| صوامت | متابعة دروس الصوامت | قيد التطوير |

## ختامًا

نرحب بملاحظاتكم واقتراحاتكم، ونتمنى لكم تجربة ممتعة مع **روافد**.
